# Data

The raw file is not stored in this repository.

1. Download `DataCoSupplyChainDataset.csv` from Mendeley Data:
   https://data.mendeley.com/datasets/8gx2fvg2k6/5
2. Save it in this folder as `data/DataCoSupplyChainDataset.csv`.

**Source:** Constante, F., Silva, F., Pereira, A. (2019). *DataCo Smart Supply Chain for Big Data Analysis*, Mendeley Data, V5. doi:10.17632/8gx2fvg2k6.5

The file has 180,519 order line items and 53 columns covering orders placed from January 2015 to January 2018. `sas/01_import_and_quality_checks.sas` documents each column position it reads.
